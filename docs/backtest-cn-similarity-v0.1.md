# 中国通胀历史相似期回测 v0.1

## 原型范围

本版仅验证中国通胀维度，使用消费品CPI、服务CPI、PPI和居民物价预期四个子主题。状态距离与过去6个月轨迹距离各占50%，返回3个相隔至少6个月的历史事件。

候选历史时期的未来6个月CPI结果必须在目标检索日之前已经完整发布，结果变量不参与相似期搜索。

## 样本外结果

- 可评价目标月份：20个。
- 相似期中位路径预测MAE：0.608。
- 当前CPI不变基线MAE：0.383。
- 三个近邻后续CPI变化平均范围：0.881个百分点。
- 相邻目标月近邻集合平均Jaccard：0.447。
- 验收结果：失败。

## 解释

表面状态和短轨迹相似并未产生收敛的后续结果。相似期榜单会随着目标月份发生中等程度变化，而且三个近邻之后的CPI路径分散较大。将这些近邻的中位变化当作预测，误差显著高于假设CPI保持当前水平。

这不代表历史类比没有展示价值。它可以用来列出多种曾经发生的路径、暴露分叉变量，并提醒用户当前组合并非唯一结局。但产品不得把最高相似度解释为“历史将重演”，也不得把近邻中位数包装成高置信预测。

## 与PRD的差距

- 当前只有中国单一维度，尚无跨国多样性。
- 没有结构制度特征，无法做结构可比性重排。
- 历史不足以执行默认10年排除期。
- 轨迹窗口只能用6个月，尚不能执行36个月主窗口。
- 无法返回三个跨国、非重复的长期历史事件。

因此本接口必须保持 `diagnostic_only`，不能进入正式首页推荐。
