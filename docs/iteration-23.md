# 第二十三迭代：术语帮助与数据白话解读 v0.1

完成内容：

- 新增统一的 `?` 术语帮助组件，鼠标悬停、键盘聚焦和手机点击均可查看解释。
- 当前研究页布置 30 个帮助实例；默认可见区域有 24 个可聚焦按钮，其余位于折叠的历史证据卡内。
- 首批覆盖：置信度、cutoff、vintage、表面相似度、状态相似、轨迹相似、结构可比性、历史路径范围、中位数、Jaccard 稳定性、证据等级 B、政策事件账本、LPR、QQE、YCC。
- 新增两块“这组数据怎么读”：一块解释历史路径分布和榜单稳定性，一块解释中日结构分数及信贷数据。
- 数据解释同时给出限制条件，避免把相似度、结构分或历史中位路径理解为预测概率。

交互与无障碍：

- 问号使用原生按钮，可通过 Tab 键到达，并提供中文 `aria-label`。
- 解释内容使用 `role=tooltip`；获得焦点时与鼠标悬停时均显示。
- 桌面端气泡靠近术语显示；720px 以下固定在屏幕底部，避免被卡片和视口裁切。
- 键盘焦点有清晰轮廓，不依赖颜色表达当前状态。

数据白话解释示例：

- Jaccard 低于 0.5：相邻月份的相似期名单变化较大，榜单对时间点敏感。
- 信贷结构：中日存量占 GDP 比重接近，但近五年扩张速度不同，不能据此判断处于同一周期。
- vintage：历史时点真正可见的数据版本；终值历史可能包含后续修订，不能冒充严格实时回测。

验收：

- 前端单元测试、ESLint、TypeScript 和生产构建通过。
- 真实浏览器验证 24 个当前可聚焦帮助按钮、2 块数据解读面板。
- 390px 视口下页面无横向溢出；控制台无错误。

下一迭代建议：把术语词典扩展到首页周期状态、四维评分、情景概率与指标详情页，并增加一个可搜索的“术语表”抽屉，避免用户逐个寻找问号。
