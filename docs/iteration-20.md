# 第二十迭代：日本企业通胀预期与结构可比性 v0.1

完成内容：

- 接入日本银行短观“全企业、全行业、未来一年总体物价预期”季度序列。
- 官方序列从 2014Q1 开始，最新值为 2026Q2 的 2.7%。
- 为不含逐期发布日期的 BOJ API 历史值采用保守可见时间：季度末后 31 天；该规则只会延迟数据，不会提前引入数据。
- 日本通胀子主题新增企业预期，但由于调查对象、单位和历史长度与中国居民预期不同，暂不纳入历史候选排名。
- 新增结构可比性 v0.1，独立于价格表面相似度，不参与历史候选重排。
- 结构维度包括劳动年龄人口趋势、通胀预期测量方式、信用环境、政策制度环境。
- 当前仅 2/4 个结构维度可评分，结构分数 56.1，置信度低；信用与政策制度保持缺失，不做主观填补。
- 前端新增结构可比性面板和日本企业通胀预期说明。

关键边界：

- 56.1 不是“日本有 56.1% 概率复刻中国”，也不是预测准确率。
- 人口分数来自两国劳动年龄人口五年变化差；预期测量分数来自公开固定规则，反映调查对象和单位不等价。
- 只有 2/4 覆盖时，结构分数不得参与综合相似度，也不得改变任何情景概率。
- 日本企业预期始于 2014 年，无法支持 1997、2008 等长历史候选的同维度比较。

官方依据：

- 日本银行将企业通胀预期分为销售价格与总体物价的一年、三年、五年预期。
- “总体物价预期”采用同比变化率；平均值排除“不清楚未来物价”的回答。
- 短观存在 2003/2004 年调查口径断点，因此后续使用更早短观数据时必须单独处理。

下一迭代建议：优先补齐中日信用环境的可比指标，例如企业融资条件、信贷增速或利率负担；政策制度维度先制定可审计的事件编码规则，再决定是否允许人工维护。
