# 第六迭代记录

## 已完成

1. 接入 Census 官方公开文本文件中的美国零售与餐饮销售，覆盖 1992 年至今，共 415 条真实月度观测。
2. 从国家统计局公开“数据发布”分页自动发现正式文章，不依赖隐藏接口。
3. 回补中国 CPI 24 个月、PPI 27 篇有效历史；旧版不兼容页面记录并跳过。
4. 将实验评分门收紧为：每个核心地域至少两个指标各自拥有 24 个月历史。
5. 新增 `/v1/experimental/environment`，输出透明维度状态、方向、覆盖、置信度及证据指标。
6. 实验 API 明确标记 `research_only`，不输出康波阶段或个人建议。

## 验证

- API：30 项测试通过。
- 数据接入门与实验评分门均通过。
- 中国 29 个月、美国 416 个月、日本 441 个月高频历史可用于下一阶段滚动回测。

## 解释限制

实验分数表示指标相对自身历史的位置，并不表示“环境好坏”。例如通胀维度的高分可能只表示价格信号相对近期低位明显回升，不能直接解释为高通胀，更不能直接推导资产或职业选择。
