# 第二十五迭代：全站可搜索术语表 v0.1

完成内容：

- 在根布局接入全站“术语表”悬浮入口，首页、研究页和指标详情页共用。
- 术语表采用侧边抽屉，支持中文、英文、缩写、类别和解释正文搜索。
- 首版收录 18 个核心词条，覆盖数据、相似期、结构、回测、统计、证据、情景、周期、政策和信用。
- 每个词条包含白话定义与“注意”项，专门说明常见误解。
- 支持打开后自动聚焦搜索框、Escape 关闭、背景关闭和显式关闭按钮。

首批词条：

- cutoff、vintage、状态相似、轨迹相似、表面相似度、结构可比性
- Jaccard 稳定性、中位数、置信度、证据等级 B、滚动回测
- 情景概率、周期时钟、LPR、QQE、YCC、信用占 GDP、政策事件账本

验收：

- 搜索 `YCC` 只返回一个对应词条。
- 搜索结果同时展示白话解释和制度阶段注意事项。
- Escape 可关闭对话框。
- 390px 视口下抽屉宽度约 375px，页面无横向溢出。
- 浏览器控制台无页面错误。
- 前端单元测试、ESLint、TypeScript 和生产构建通过。

下一迭代建议：让页面中的问号与术语表使用同一份词典数据，避免两处解释长期漂移；点击问号时可提供“在术语表中查看更多”入口。
