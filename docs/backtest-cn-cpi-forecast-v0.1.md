# 中国CPI滚动样本外预测回测 v0.1

## 结论

预测门槛未通过。v0.4环境分数虽然通过结构稳定性检查，但现有样本不能证明它比简单基线更能预测未来CPI。

### 未来6个月平均CPI

- 真正滚动样本外预测：5个。
- 分数校准模型：MAE 0.600，RMSE 0.675。
- 当前值不变基线：MAE 0.587，RMSE 0.669。
- 3个月趋势外推：MAE 0.973，RMSE 1.031。
- 分数模型未击败最佳基线，且预测点少于预设的12个。

### 未来12个月平均CPI

没有形成合格预测点。原因是当前严格 vintage 的中国月度通胀数据历史不足；在要求至少8个已经成熟的训练标签后，没有剩余的可评估起点。

## 方法

- 预测目标：起点可见的最新CPI之后，未来6个月或12个月CPI同比均值。
- 预测起点的环境分数严格使用当月15日23:59前已发布数据。
- 扩展窗口训练只允许使用目标期已经完整发布的旧样本。
- 模型预测为 `当前CPI + beta × v0.4环境分数`，beta只用当时成熟标签估计。
- 基线一是假设未来均值等于当前CPI；基线二按最近3个月斜率外推。
- 方向评价使用±0.05个百分点中性区间，避免把“预测不变”错误算作上涨判断。

## 决策含义

当前看板可以继续作为环境整理和风险讨论工具，但不能宣称具有通胀预测优势，更不能把分数直接映射成人生或投资行动。下一次有效检验需要补齐更早的逐月CPI、PPI分类项以及逐季度央行预期报告，并保持每条数据的原始发布时间。
