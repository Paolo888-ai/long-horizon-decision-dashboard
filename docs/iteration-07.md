# 第七迭代记录

## 已完成

1. 将原始资产采集时间与观测公开可用时间分开。
2. 从国家统计局正式页面恢复历史发布时间，并按 UTC 存储可用时间。
3. 增加双重防泄漏：公开时间不晚于 cutoff，观测日期也不得晚于 cutoff。
4. 建立中国通胀维度严格 vintage 月度回测。
5. 增加状态切换、转折、短状态、波动率和 leave-one-out 敏感度诊断。
6. 新增 `/v1/backtests/cn-inflation` 和 `backtest-cn-inflation` CLI。
7. 建立模型门：至少24个月、月度变化标准差不超过15、单指标最大影响不超过25。

## 首次结果

数据回测链可用，但模型门未通过。主要问题不是数据泄漏，而是两个指标构成的通胀维度对单一指标过于敏感。因此实验分数继续保持研究用途，不接入正式首页和人生建议。

## 验证

- API：33项测试通过。
- 严格回测：27个有效 cutoff，其中26个同时包含 CPI 和 PPI。
- SQLite 时区边界已统一按 UTC 比较；生产 PostgreSQL 使用带时区字段。
