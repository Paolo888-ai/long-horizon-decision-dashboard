# 第八迭代记录

## 已完成

1. 从既有国家统计局 CPI 页面归档派生核心 CPI，无需重复下载。
2. 增加派生去重、可重复运行和旧格式失败保护。
3. 核验29个月核心 CPI 值及正式发布时间。
4. 建立消费价格、生产价格两级子主题聚合。
5. 增加3个月平滑和连续两期状态确认。
6. 生成 v0.1/v0.2 同 cutoff 对照回测与 API。

## 结果

v0.2 的波动和状态切换明显下降，但单指标最大敏感度没有改善，总模型门仍失败。下一轮应优先增加第三个独立通胀子主题，例如工资、服务价格或通胀预期；不能通过放宽25分阈值让模型人为过关。

## 验证

- API：35项测试通过。
- 数据：24个指标中21个有真实观测，覆盖87.5%。
- 回测：v0.2共27个有效 cutoff，26个含三项指标。
