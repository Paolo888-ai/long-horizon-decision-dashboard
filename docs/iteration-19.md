# 第十九迭代：严格回测与跨国回顾性证据分层

完成内容：

- 新增 `/v1/research/cn-jp-inflation-similarity` API，向前端提供中日通胀回顾性比较结果。
- 研究页保留原中国严格 vintage 证据卡，并新增独立的“证据层 B：回顾性跨国比较”。
- 日本证据固定展示“终值历史 · 非严格 vintage”“禁止并入预测概率”和全部未通过原因。
- 展示日本 2008-04、2013-06、1997-10 三条参考路径，包含状态相似、轨迹相似和事后六个月 CPI 变化。
- 不合并中国与日本候选排名，不让日本相似度改变中国严格回测的置信度或结论。
- 新 API 拒绝不含时区的 cutoff，避免产生含糊的数据可见时间。
- 完成真实浏览器桌面和 390px 移动端验收；无横向溢出，控制台无错误。
- API 测试增至 50 项；前端 ESLint、3 项测试及生产构建全部通过。

产品边界：

- 证据层 A 是中国严格历史版本回测，但预测表现仍未通过基线门槛。
- 证据层 B 是日本当前终值长历史的回顾性比较，不能被称为预测回测。
- 两层证据都不能直接生成投资、职业、迁移或家庭决策建议。

下一迭代建议：接入日本央行短观中的销售价格判断或通胀预期数据，形成第四个独立子主题；同时建立“结构可比性”维度，把人口、信用、政策制度差异作为单独分数展示，而不是继续提高表面相似度权重。
