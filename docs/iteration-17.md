# 第十七迭代：历史相似证据卡前端

完成内容：

- 新增 `/research/similarity` 研究页面，直接读取真实证据卡 API，不使用样例类比数据。
- 在主看板“历史镜像”区新增“查看回测证据”入口。
- 提供回测月份选择，并限制为后续路径已经成熟的月份。
- 常驻展示“高置信类比已拒绝”、置信度上限和全部拒绝原因。
- 展示路径范围、路径中位变化和连续月份近邻 Jaccard 稳定性。
- 展示三条可展开历史路径，包括表面相似度、状态/轨迹分数、主要相似、关键差异及事后路径。
- 对结构分数缺失和“历史相似不等于历史重演”进行显著提示。
- 完成真实浏览器桌面与 390px 移动端验收；月份切换正常、无横向溢出、控制台无错误。

边界说明：

- 当前证据仍只有中国通胀维度，不能形成跨国或制度结构重排。
- 当前历史长度不足以实现 PRD 中的十年隔离和 36 个月轨迹窗口。
- 类比路径的回测误差尚未战胜 CPI 持续性基线，因此页面只提供低置信研究证据，不输出人生决策结论。

下一迭代建议：增加中国以外的可比通胀历史，优先接入日本；随后加入制度、人口、信用和估值等结构特征，重新检验类比算法能否稳定优于简单基线。
