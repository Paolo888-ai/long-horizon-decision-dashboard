## 设计决定

- 首页继续显示“样例数据”，因为三个年度指标不足以形成月度周期结论；
- 中国数据提供官方文件导入通道，不依赖未经正式承诺的隐藏接口；
- FRED 请求 URL 入库前会移除 API Key；
- 免费可访问不等于允许公开再分发，来源授权状态继续保留在注册表；
- 数据质量的 100% 是 12 个种子指标的覆盖率，不代表完整 40 指标 MVP。
