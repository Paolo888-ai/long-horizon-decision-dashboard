## 未完成原因

### 美国

BLS Public Data API 在当前执行网络环境返回 403 Access Denied，JSON POST 和单系列 GET 均无法通过其边缘网关。代码和离线契约测试已经完成，但没有把失败请求计入真实覆盖。

可选后续路径：

1. 在云端私测环境重新执行 BLS 连接器；
2. 配置 FRED API Key，并逐系列确认再展示权；
3. 使用 BLS 官方下载文件导入，但当前环境访问下载域名超时。

### 中国

CPI、PPI、工业增加值三个指标定义和标准 CSV 导入通道已完成，仍缺官方原始文件。系统不使用未承诺的隐藏接口，也不根据新闻文字人工伪造时间序列。

## 质量门规则

1. 总体有效指标覆盖不低于 70%；
